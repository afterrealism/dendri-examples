# Vue Example

The smallest React integration — `createDendriStore()` wrapped with a Vue `ref`.

Part of the [Dendri examples](../). See the [root README](../README.md) for server config; this
demo reads `VITE_DENDRI_URL` + `VITE_DENDRI_API_KEY` (defaults to `ws://localhost:9876`).

## Run

```bash
npm install
npm run dev
```

Open in two tabs to see the room sync.
