# Video Chat

WebRTC audio/video calls with rooms — join a room by URL and connect peer-to-peer media
through Dendri's `MediaConnection`.

Part of the [Dendri examples](../). See the [root README](../README.md) for how to point at a
hosted (`PUBLIC_DENDRI_URL` + `PUBLIC_DENDRI_API_KEY`) or self-hosted signaling server.

## Run

```bash
npm install
npm run dev
```

Open the printed URL in two browser tabs (allow camera/mic) to start a call.
