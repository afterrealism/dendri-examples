# File Transfer

Send files directly between browsers over a Dendri data connection, with relay fallback on hostile networks.

Part of the [Dendri examples](../). See the [root README](../README.md) for how to point at a
hosted (`PUBLIC_DENDRI_URL` + `PUBLIC_DENDRI_API_KEY`) or self-hosted signaling server.

## Run

```bash
npm install
npm run dev
```

Open the printed URL in two browser tabs to watch peers sync in real time.
